# Covid--19-Global-Impact-Dashboard
A COVID-19 data analysis and interactive Power BI dashboard project using Excel, Python, Pandas, Matplotlib, and Power BI.
📌 Project Overview

The COVID-19 Global Impact Dashboard is a data analysis and visualization project developed to explore the global impact of the COVID-19 pandemic.

The project uses Excel, Python, and Power BI to analyze important indicators such as total cases, total deaths, cases per million, vaccination coverage, and COVID-19 trends.

🎯 Objectives
Analyze COVID-19 cases and deaths across countries.
Compare countries using population-normalized indicators.
Analyze COVID-19 case trends over time.
Examine vaccination coverage.
Calculate the Case Fatality Rate.
Create an interactive dashboard using Power BI.
Perform basic data analysis using Python.
